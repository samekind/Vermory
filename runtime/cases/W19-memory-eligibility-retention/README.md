# W19 Memory Eligibility And Retention

W19 qualifies the difference between current eligibility, historical archive,
and authorized forgetting.

The profile binds four product trajectories:

- `G01-language-default-local-override`;
- `S01-deletion-and-source-injection`;
- `C02-housing-viewing-validity`;
- `W03-workspace-workaround-validity`.

The corpus contains active, future, expired, archived, superseded, and deleted
controls. Accelerated timestamps are qualification boundaries, not a claim of
days, months, or years of uninterrupted wall-clock operation.

W19 does not add a retention-class enum or a scheduler. PostgreSQL authority,
continuity, lifecycle, temporal validity, archive, and forgetting remain
separate governed dimensions.
